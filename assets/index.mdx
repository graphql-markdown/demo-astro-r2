---

Every page in this site was generated from the
[AniList](https://anilist.co/) GraphQL schema by
[GraphQL-Markdown](https://graphql-markdown.dev/) and written straight to a
Cloudflare R2 bucket through an [output
adapter](https://graphql-markdown.dev/docs/advanced/output-adapter) — no
generated file was ever written to disk.

This site reads them back out of the bucket through a custom Astro content
loader, so regenerating the documentation reaches the site through a rebuild
and a deploy.
